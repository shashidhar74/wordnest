# WordNest

**A full-stack blog with a publishing workflow, threaded comments and an AI assistant.**
A personal learning project by Shashi.

🌐 **Live:** https://wordnest-f2mv.onrender.com
📖 **API docs (Swagger):** https://wordnest-api-16oz.onrender.com/docs

> Hosted on Render's free plan: the first visit after ~15 minutes idle takes 30–60 s while the services wake up.

## Features

- **Posts:** create and edit posts with an image; search and paging
- **Roles:** `user` reads, `creator` writes, `admin` reviews
- **Publishing workflow:** draft → submit → pending → approve / reject / send back for clarification → published → closed
- **Visibility rules:** guests and users see only published posts; creators also see their own; admins see everything
- **Threaded comments:** comments and replies (2 levels), edit, delete (soft delete keeps the replies)
- **AI (Gemini):** "Summarize with AI" on posts, "Write with AI" drafts a post from a topic, tone and keywords
- **Chat assistant:** finds posts, summarizes them, opens the editor with a topic, gives status-wise reports,
  shows rejection reasons and exports the post list as CSV, using an **intent model trained in this repo**
  (scikit-learn, 87% test accuracy)

## Tech stack

| Part | Technology |
|---|---|
| Frontend | Angular, Tailwind CSS |
| Backend | Node.js, Express 5, raw SQL with `pg`, express-validator, JWT, multer |
| Database | PostgreSQL 17 (Neon in production) |
| AI service | Python, FastAPI, scikit-learn (TF-IDF + logistic regression) |
| LLM | Google Gemini API |
| Hosting | Render (static site + 2 web services), Neon (Postgres) |

## Run locally

Needs Node 24, Python 3.13 and PostgreSQL 17.

```powershell
npm run install:all                      # root + backend + frontend packages
cp backend/.env.example backend/.env     # then fill in the values

# AI service (once)
cd ai-service
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
cd ..

npm run dev                              # backend :3000, frontend :5000, AI service :8000
```

Open http://localhost:5000. Tests: `npm run test:ai` (AI service), `npm run test:run --prefix frontend`.

## Deploy

`render.yaml` is a Render Blueprint: **New → Blueprint** → this repo creates all three services.
Set `DATABASE_URL` (Postgres connection string with `sslmode=verify-full`) and `GEMINI_API_KEY`
in the Render dashboard; `JWT_SECRET` is generated by Render.
